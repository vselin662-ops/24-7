## 3. АННОТАЦИЯ И ТЕХНИЧЕСКАЯ НОВИЗНА (NOVELTY STATEMENT)

Программный комплекс **Selin_AI** представляет собой пионерное решение в области автоматизации клиентских коммуникаций и персональной продуктивности на базе ИИ. Техническая новизна и приоритет разработки Вадима Селина Юрьевича подтверждаются следующими ключевыми факторами:

1. **Первый в экосистеме MAX Messenger двунаправленный голосовой конвейер:**  
   Разработана и внедрена уникальная сквозная логика обработки, преобразующая входящий голосовой поток пользователя из MAX Messenger во временный оптимизированный формат, осуществляющая мгновенную расшифровку через специализированный кластер распознавания (STT Whisper-large-v3 на инфраструктуре Groq), обрабатывающая интент через многоагентный оркестратор и мгновенно генерирующая естественный речевой ответ (TTS Edge-TTS) с двухэтапной загрузкой речевого синтеза обратно в MAX (`/uploads` -> `/messages`).

2. **Экономическая и инфраструктурная автономность:**  
   Программа решает фундаментальную проблему зависимости от проприетарных платных API с жесткими дневными квотами (например, Google Gemini Live). Использование кастомных интеграций с Edge-TTS и Groq Whisper-large-v3 обеспечивает неограниченный (вечный) бесплатный цикл транскрипции и синтеза без риска исчерпания лимитов.

3. **Интеграция когнитивных систем (SM-2 и Shadowing):**  
   Интегрирован алгоритм интервального повторения SuperMemo-2 (SM-2) для адаптивного обучения пользователей иностранным языкам и профессиональным скриптам продаж, совмещенный со звуковым анализом техники Shadowing (имитация речи диктора).

4. **Уникальная логика маршрутизации и оркестрации:**  
   Оригинальный управляющий автомат (State Machine), разработанный автором в `server.ts`, полностью координирует переключения между текстовыми и голосовыми режимами на основе анализа контекста, метаданных вложений и лексических маркеров.

## 4. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА (TECHNICAL SPECIFICATION)

Архитектурное решение Selin_AI выражено в виде модульной программной структуры, функционирующей в облачной распределенной среде.

### 4.1. Стек технологий и инфраструктура
* **Server Runtime:** Node.js v20+ / TypeScript (строгая типизация данных).
* **Framework:** Express JSON API с кастомной middleware-маршрутизацией.
* **Облачный хостинг:** Railway Cloud Container Service (автоматическое масштабирование, деплой из изолированного репозитория).
* **Слой хранения данных (Data Layer):**  
  * Реляционная база данных SQLite в режиме WAL (Write-Ahead Logging) для сверхбыстрых операций ввода-вывода.
  * Firebase Cloud Firestore + Firebase Authentication (persistent cloud storage для профилей клиентов и прав доступа).

### 4.2. Модули искусственного интеллекта и конвейера обработки
* **LLM Orchestrator Core:**  
  * Основная модель: `llama-3.3-70b-versatile` (Groq API) — обеспечивает задержку (TTFT) менее 120мс при сложной оркестрации.
  * Резервная модель (fallback): `gemma2-9b-it` — автоматическое переключение при превышении лимитов Rate Limits (429/503).
* **Speech-to-Text (STT) Module:**  
  * Модель: `whisper-large-v3` (через Groq API).
  * Формат входного аудио: нативное извлечение `.ogg` / `.mp3` из вложений MAX API.
* **Text-to-Speech (TTS) Module:**  
  * Технология: Microsoft Edge Translation & Speech API (`msedge-tts`).
  * Голос по умолчанию: `ru-RU-SvetlanaNeural` (выборка 24kHz, 48kbps, моно MP3/OPUS).
* **Multimedia Generation Engine:**  
  * Изображения: Открытый REST API Pollinations.ai (генерация на базе диффузионных моделей Flux-1) без API-ключей и лимитов.
  * Код: Выделенный агент написания кода на базе `Qwen-2.5-Coder-32b`.

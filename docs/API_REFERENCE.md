# Справочник API платформы SELIN

Документация программного интерфейса (API) для интеграции с сервисом SELIN.

---

## Аутентификация

Все защищенные запросы к API требуют передачи токена доступа в заголовке `Authorization`:

```http
Authorization: Bearer <your_jwt_token>
```

---

## Таблица эндпоинтов

| Метод | Эндпоинт | Доступ | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | Публичный | Проверка работоспособности сервиса |
| `GET` | `/api/user/balances` | Защищенный | Получение текущего баланса и лимитов пользователя |
| `POST` | `/api/calculator/eval` | Публичный | Безопасное вычисление математических выражений |
| `POST` | `/api/tts` | Защищенный | Синтез речи из текста (голосовой помощник) |
| `GET` | `/api/company/config` | Защищенный | Получение конфигурации компании |
| `POST` | `/api/company/config` | Защищенный | Обновление настроек компании |

## Примеры запросов и ответов

### 1. Проверка состояния системы
**Запрос:**
```bash
curl -X GET https://api.selin.app/api/health
```

**Ответ:**
```json
{
  "status": "ok",
  "timestamp": "2026-08-09T10:00:00Z"
}
```

### 2. Вычисление математических выражений
**Запрос:**
```bash
curl -X POST https://api.selin.app/api/calculator/eval \
  -H "Content-Type: application/json" \
  -d '{"expr": "1500 * 1.2"}'
```

**Ответ:**
```json
{
  "result": 1800
}
```

### 3. Синтез речи (TTS)
**Запрос:**
```bash
curl -X POST https://api.selin.app/api/tts \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Здравствуйте! Ваш заказ готов."}'
```

## Ограничения частоты запросов (Rate Limits)

Для обеспечения стабильности системы действуют следующие лимиты:
- **Общий API**: до 100 запросов в минуту на один IP/пользователя.
- **Ресурсоемкие операции (TTS/Синтез речи)**: до 10 запросов в минуту.

В случае превышения лимита сервер возвращает статус `429 Too Many Requests`.

---

## Коды ошибок

| Код | Статус | Причина и решение |
| :--- | :--- | :--- |
| `200` | OK | Запрос успешно выполнен |
| `400` | Bad Request | Неверные входные параметры в теле запроса |
| `401` | Unauthorized | Отсутствует или недействителен токен авторизации |
| `429` | Too Many Requests | Превышен лимит частоты запросов |
| `500` | Internal Server Error | Внутренняя ошибка сервера. Обратитесь в поддержку |

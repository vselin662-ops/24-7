# Архитектура системы Selin AI 2.0

Этот документ описывает техническую архитектуру, потоки данных и структуру модулей голосовой мультиагентной платформы **Selin AI**. Документ составлен для владельца и инженеров проекта.

---

## 1. Схема потоков данных (Data Flow)

Движение запроса и ответа в системе происходит по следующему сквозному маршруту:

```text
[ Пользователь ]
       │
       ▼ (Аудио вложение или Текст сообщения)
[ Адаптеры интеграции (src/adapters/) ] 
   - MaxAdapter (Мессенджер MAX)
   - TelegramAdapter (Телеграм-бот)
   - WebAdapter (Веб-интерфейс)
       │
       ▼ (Нормализованный текстовый запрос + контекст чата)
[ Оркестратор (src/core/AgentOrchestrator.ts) ]
   - Извлечение намерений (Intent Engine)
   - Маршрутизация на основе типов задач (Task Routing)
       │
       ▼ (Выбранная задача & Контекст)
[ Специализированный Агент (src/agents/) ]
   - Унаследованы от BaseAgent
   - Каждый агент решает свою задачу (WeatherAgent, TravelAgent, NewsAgent, etc.)
       │
       ▼ (Запросы к сторонним API / база данных / LLM)
[ Внешние Сервисы & Коннекторы (src/services/ & src/connectors/) ]
   - FlightService / TravelPayouts (Авиабилеты)
   - TTSService (Синтез речи)
   - Weather API / wttr.in (Погода)
   - SQLite DB / Firestore (Локальная база данных и облачный архив)
       │
       ▼ (Сформированный текстовый ответ)
[ Система Синтеза Речи (src/services/TTSService.ts) ]
   - Нормализация чисел, дат, валют в русский текст (textUtils.ts)
   - Генерация аудио в формате MP3 через MS Edge TTS
       │
       ▼ (Голосовой файл MP3 + Текст)
[ Адаптер Отправки ] ➔ [ Пользователь (в чате воспроизводится голос) ]
```

---

## 2. Описание всех модулей в `src/`

* **`src/adapters/`** — Модули связи с мессенджерами (MAX, Telegram, Web), преобразующие сообщения платформ во внутренний формат Selin AI.
* **`src/agents/`** — Интеллектуальные агенты (Weather, Travel, News, Order, Tutor, Sales, Support), выполняющие конкретные задачи пользователя.
* **`src/assets/`** — Статические графические элементы, иконки и медиа-ресурсы, используемые в интерфейсе.
* **`src/components/`** — Визуальные React-компоненты фронтенда (панель FAQ, диктофон, окно чата, списки настроек).
* **`src/config/`** — Настройки приложения, константы проекта, валидация и автоматическая корректировка переменных окружения.
* **`src/connectors/`** — Коннекторы к внешним сервисам доставки, такси, авиабилетов, Instagram и генераторам бизнес-планов.
* **`src/core/`** — Ядро платформы: распределитель задач (Orchestrator), управление памятью (MemorySystem), обработка эмоций и вызов LLM.
* **`src/data/`** — Статические справочные наборы данных, шаблоны документов и системные списки.
* **`src/database/`** — Логика подключения к локальным и облачным хранилищам, хранение истории сессий.
* **`src/fintech/`** — Модули эквайринга, обработки платежей (ЮKassa, Robokassa), поддержки СБП и операций с Цифровым Рублем.
* **`src/handlers/`** — Обработчики вебхуков и асинхронных событий, связывающие Express с логикой ядра.
* **`src/hooks/`** — Пользовательские хуки React для связи интерфейса с микрофоном, аудио-плеером и сервером.
* **`src/lib/`** — Низкоуровневые системные утилиты: обертка над SQLite (pure-sqlite), конвертер аудиофайлов (audioConvert).
* **`src/middleware/`** — Промежуточные обработчики Express (безопасность, проверка токенов, логирование, защита от атак).
* **`src/modules/`** — Изолированные бизнес-модули, такие как интерактивное обучение языкам (language) и бизнес-менторство.
* **`src/repositories/`** — Слой абстракции данных для прямого сохранения и чтения сущностей в базе данных.
* **`src/routes/`** — Маршруты REST API сервера (платежи, синтез голоса, аудит безопасности, логи авторизации).
* **`src/services/`** — Прикладные бэкенд-сервисы (синтез TTS, распознавание STT, авиабилеты, мониторинг агентов, защита от джейлбрейков).
* **`src/utils/`** — Вспомогательные функции для очистки текста, форматирования чисел и детектирования активационных слов (wake-word).

## 3. Матрица зависимостей модулей (Dependency Matrix)

Для поддержания модульности и предотвращения циклической зависимости в Selin AI 2.0 установлена строгая иерархия импортов:

```text
┌────────────────────────────────────────────────────────┐
│                      src/adapters                      │  (Точка входа)
└───────────────────────────┬────────────────────────────┘
                            │ использует
                            ▼
┌────────────────────────────────────────────────────────┐
│                        src/core                        │  (Ядро, LLM и Память)
└───────────────────────────┬────────────────────────────┘
                            │ оркестрирует
                            ▼
┌────────────────────────────────────────────────────────┐
│                       src/agents                       │  (Интеллект и Роли)
└───────────────────────────┬────────────────────────────┘
                            │ обращается к
                            ▼
┌────────────────────────────────────────────────────────┐
│              src/services & src/connectors             │  (Инструменты и API)
└───────────────────────────┬────────────────────────────┘
                            │ сохраняет и считывает
                            ▼
┌────────────────────────────────────────────────────────┐
│            db.ts (root) & src/database & src/lib       │  (База данных и Утилиты)
└────────────────────────────────────────────────────────┘
```

1. **Адаптеры (`src/adapters`)** зависят от **Ядра (`src/core`)**, чтобы передавать туда сообщения пользователей, и от **Сервисов (`src/services`)** для отправки ответов (например, загрузка файлов, синтез голоса).
2. **Ядро (`src/core/AgentOrchestrator`)** импортирует и инициализирует всех **Агентов (`src/agents`)**.
3. **Агенты (`src/agents`)** зависят от **Сервисов (`src/services`)** и **Коннекторов (`src/connectors`)** для выполнения реальных действий (запрос погоды, поиск рейсов, отправка писем).
4. **Все модули** могут использовать **Служебные утилиты (`src/utils`)** и обращаться к глобальному хранилищу **`db.ts`** для сохранения прогресса, контекста сессии и настроек голоса.

# Переменные окружения (Environment Variables)

В этом файле перечислены все переменные окружения (`process.env`), используемые в **Selin AI 2.0**, их назначение, способы получения и последствия отсутствия.

---

## 1. Обязательные системные переменные

Без этих переменных запуск проекта или ключевой функционал голосового общения **невозможен**.

### `GEMINI_API_KEY`
*   **Назначение:** Ключ для работы с моделями Google Gemini (например, `gemini-2.5-flash`), отвечающими за работу всех агентов, интеллектуальные диалоги, RAG и извлечение намерений.
*   **Где взять:** В панели разработчика [Google AI Studio](https://aistudio.google.com/).
*   **Что сломается без неё:** Приложение не сможет отвечать на сообщения. Модуль `LLMService` выбросит критическую ошибку на старте.

### `MAX_BOT_TOKEN`
*   **Назначение:** Токен авторизации бота в мессенджере MAX.
*   **Где взять:** В панели управления ботами мессенджера MAX или у администрации платформы MAX.
*   **Что сломается без неё:** Бот Selin AI не сможет принимать входящие сообщения от пользователей и отправлять ответы. Связь с пользователями будет полностью разорвана.

### `GROQ_API_KEY`
*   **Назначение:** Ключ для работы с высокоскоростным API Groq. Используется для мгновенной транскрипции голосовых сообщений пользователей через модель **Whisper-large-v3** (STT), а также в качестве быстрого резервного текстового движка (Llama-3.3).
*   **Где взять:** В личном кабинете [Groq Console](https://console.groq.com/).
*   **Что сломается без неё:** Пользователи не смогут отправлять голосовые сообщения. Бот будет отвечать текстовой ошибкой «Не удалось распознать аудиосообщение».

### `JWT_SECRET`
*   **Назначение:** Секретная строка для шифрования и подписи JWT-токенов администраторов и сессий веб-интерфейса.
*   **Где взять:** Сгенерировать случайную строку длиной от 32 символов.
*   **Что сломается без неё:** Если не задана, система автоматически использует дефолтный небезопасный ключ, выводя предупреждение. Авторизованные сессии могут быть скомпрометированы.

## 2. Опциональные системные настройки

### `PORT`
*   **Назначение:** Порт, на котором запускается Express-сервер. По умолчанию: `3000`.
*   **Что сломается без неё:** Ничего не сломается, проект автоматически запустится на порту `3000`.

### `NODE_ENV`
*   **Назначение:** Режим сборки (`production` или `development`).
*   **Что сломается без неё:** Влияет на детализацию логов. В `production` логи пишутся в лаконичном JSON-формате, отключаются отладочные трассировки стека ошибок.

### `APP_URL`
*   **Назначение:** Полный публичный адрес сервера (например, `https://selin-ai.railway.app`). Необходим для корректного формирования абсолютных ссылок на аудиофайлы при загрузке их в хранилище MAX Storage.
*   **Что сломается без неё:** Могут возникнуть сбои при отправке голосовых сообщений в MAX — мессенджер не сможет скачать сгенерированный аудиофайл с бэкенда.

### `EDGE_TTS_VOICE`
*   **Назначение:** Базовый голос синтеза речи по умолчанию (мужской). По умолчанию: `ru-RU-DmitryNeural`.
*   **Что сломается без неё:** Применится стандартный голос `ru-RU-DmitryNeural`.

### `DISABLE_LLM_CACHE`
*   **Назначение:** Отключение локального кэша ответов LLM (при значении `true`). Используется только при тестировании.
*   **Что сломается без неё:** Без этой переменной включено кэширование, что экономит до 40% расходов на API. При значении `true` каждый запрос будет повторно отправляться в платный API, увеличивая расходы и замедляя ответы.

## 3. Интеграции сторонних Агентов (Инструменты)

Без этих ключей соответствующие агенты перейдут в режим ограниченных возможностей (фолбэк-заглушки).

### `WEATHER_API_KEY` (или `OPENWEATHER_API_KEY`)
*   **Назначение:** Ключ доступа к OpenWeatherMap API для получения точной погоды по городам в реальном времени.
*   **Где взять:** На сайте [OpenWeatherMap](https://openweathermap.org/).
*   **Что сломается без неё:** Погодный агент автоматически переключится на бесплатный резервный шлюз `wttr.in`. Погода продолжит работать, но скорость ответов и стабильность при высоких нагрузках могут снизиться.

### `TRAVELPAYOUTS_TOKEN` (или `AVIASALES_API_KEY`)
*   **Назначение:** Партнерский токен Aviasales для поиска реальных авиабилетов и цен.
*   **Где взять:** В личном кабинете [Travelpayouts](https://www.travelpayouts.com/).
*   **Что сломается без неё:** `TravelAgent` не сможет найти реальные билеты и будет сообщать пользователю о временной недоступности поиска авиабилетов, предлагая общие советы по путешествиям.

### `YANDEX_EDA_API_KEY` (или `DODO_API_KEY`)
*   **Назначение:** Интеграция с агрегаторами доставки еды.
*   **Что сломается без неё:** Функции автозаказа еды через агента `OrderAgent` будут отключены, агент выдаст ошибку отсутствия ключа интеграции.

### `YANDEX_GO_API_KEY` (или `YANDEX_TAXI_CLID` / `YANDEX_TAXI_B2B_TOKEN`)
*   **Назначение:** Вызов такси и расчет стоимости поездок.
*   **Что сломается без неё:** Функция расчета стоимости и заказа поездок заблокируется с выводом предупреждения о необходимости настройки ключей.

## 4. Переменные платежных систем (Биллинг)

### `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`
*   **Назначение:** Автоматический эквайринг и прием платежей банковскими картами РФ через ЮKassa.
*   **Где взять:** В личном кабинете [ЮKassa](https://yookassa.ru/) после заключения договора.
*   **Что сломается без неё:** Пользователи не смогут оплатить подписку картами Visa/Mastercard/МИР в автоматическом режиме. Оплата картами выдаст техническую ошибку.

### `ROBOKASSA_MERCHANT_ID` и `ROBOKASSA_SECRET_KEY`
*   **Назначение:** Резервный шлюз оплаты (Робокасса), включая СБП и операции с Цифровым Рублем.
*   **Что сломается без неё:** Возможность оплаты через Робокассу и Цифровой Рубль будет скрыта или выдаст ошибку конфигурации.

### `SBP_PHONE`
*   **Назначение:** Номер телефона получателя для ручной оплаты подписки по Системе Быстрых Платежей.
*   **Что сломается без неё:** На экране ручной оплаты пользователь увидит надпись «укажи в настройках» вместо номера телефона.

## 5. Облачные бэкапы и безопасность

### `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`
*   **Назначение:** Авторизация сервисного аккаунта Google Firebase для синхронизации баз данных и облачного хранения логов безопасности и слепков голоса.
*   **Где взять:** В настройках проекта консоли Firebase (раздел «Service Accounts» -> создать приватный ключ).
*   **Что сломается без них:** Облачные резервные копии диалогов и планов создаваться не будут. Биометрические слепки голоса будут храниться только в локальной БД SQLite без распределенного дублирования.

### `ADMIN_CHAT_ID`
*   **Назначение:** Идентификатор чата администратора в мессенджере MAX / Telegram.
*   **Что сломается без неё:** Оповещения о критических системных ошибках, попытках взлома (джейлбрейках) и успешных платежах будут записываться только в консольные логи сервера, лишая администратора оперативного контроля.

### `SECURITY_MASTER_KEY`
*   **Назначение:** Мастер-пароль администратора безопасности для управления заблокированными IP и пользователями через защищенные эндпоинты API.
*   **Что сломается без неё:** По умолчанию применится значение `"selin_sec_master_key_2026"`, что небезопасно в производственной среде.

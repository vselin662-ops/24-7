# Чеклист внедрения и подключения менеджера SELIN

Пошаговое руководство для менеджера по запуску и настройке системы SELIN в компании.

---

## Подготовительный этап

- [ ] **Шаг 1**: Получить учетную запись администратора компании в системе SELIN.
- [ ] **Шаг 2**: Проверить доступность основного веб-интерфейса управления.
- [ ] **Шаг 3**: Пройти первичный инструктаж по функционалу системы.

---

## Настройка рабочей среды

- [ ] **Шаг 4**: Заполнить профиль компании (название, описание услуг, контакты поддержки).
- [ ] **Шаг 5**: Загрузить актуальные корпоративные регламенты и частые вопросы в базу знаний.
- [ ] **Шаг 6**: Настроить токен Telegram-бота для связи с клиентами.
- [ ] **Шаг 7**: Настроить роли и права доступа для сотрудников (модераторы, операторы).

---

## Тестирование и запуск

- [ ] **Шаг 8**: Выполнить тестовый запрос в Telegram-бот и проверить корректность работы ИИ-ассистента.
- [ ] **Шаг 9**: Проверить попадание диалога в очередь модерации и подтвердить ответ вручную.
- [ ] **Шаг 10**: Проверить работу функции голосовых сообщений.
- [ ] **Шаг 11**: Перевести систему в рабочий режим для обработки реального потока клиентов.

---

## Ежедневный контроль

- [ ] **Шаг 12**: Регулярно проверять раздел «Очередь модерации» в течение рабочего дня.
- [ ] **Шаг 13**: Анализировать журнал выполненных действий и качество ответов ассистента.
- [ ] **Шаг 14**: Дополнять базу знаний новыми кейсами по мере появления нестандартных вопросов от клиентов.

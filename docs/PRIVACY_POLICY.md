## 2. Какие данные мы собираем
2.1. Идентификатор пользователя в MAX (chat_id).
2.2. Текстовая расшифровка голосовых сообщений (обрабатывается через API Groq Whisper).
2.3. История диалогов для улучшения качества ответов.

## 3. Как мы используем данные
3.1. Данные не передаются третьим лицам, кроме поставщиков инфраструктуры (Groq, Microsoft Edge TTS) для выполнения технических функций.
3.2. Данные не используются для таргетированной рекламы.

## 4. Безопасность
4.1. Все данные передаются по защищенным каналам (HTTPS/TLS).
4.2. Доступ к базе данных ограничен и защищен токенами авторизации.

## 5. Права пользователя
5.1. Пользователь вправе запросить удаление своих данных, отправив команду /delete_data в боте.

## 2. Модули экосистемы

### 2.1 Бот (адаптеры)
* **MAX (`MaxAdapter.ts`)**: Полноценный адаптер с поддержкой входящих текстовых и голосовых сообщений, отправки аудио-ответов (в формате MP3), управления inline-кнопками (`inline_keyboard`), загрузки и скачивания изображений для Vision-запросов, а также интеллектуального разбиения длинных текстовых сообщений до 8000 символов.
* **Telegram (`telegram.adapter.ts`)**: Реализован в виде заготовки/мока со всеми методами отправки/приема контента, осуществляющего логгирование операций Winston-логгером.
* **Остальные адаптеры (`robot.adapter.ts`, `web.adapter.ts`)**: Описаны в виде интерфейсов, готовых к приему команд.

### 2.2 Админка
* **Где живёт**: HTTP роуты описаны в `src/routes/admin.routes.ts`, а логика сохранения/изменения данных реализована в `src/services/adminService.ts`. На фронтенде административные дашборды представлены вкладками и панелями: `AnalyticsPanel.tsx`, `KnowledgeBasePanel.tsx`, `ModerationPanel.tsx`, `SettingsPanel.tsx`, `StaffFeed.tsx`.
* **Что умеет**:
  * Получение текущего системного статуса и аптайма (`GET /api/admin/status`).
  * Чтение и изменение глобальных конфигураций компании (Company Config: `is_live`, каналы, отрасль, название бренда).
  * Получение системных метрик (`GET /api/admin/metrics`) и ленты событий операторов/ИИ в реальном времени (`GET /api/admin/feed`).
  * Получение списка чатов и истории переписки из СУБД SQLite.
  * Ручная модерация предложенных ИИ-ответов оператором: одобрение, отклонение, редактирование (`POST /api/moderation/action`).
  * Полный цикл управления RAG базой знаний: загрузка текстового контента, PDF и DOCX файлов, извлечение чистого текста через библиотеки `pdf-parse` и `mammoth`, дробление на чанки и их сохранение (`POST /api/knowledge/upload`, `POST /api/knowledge/delete`).
* **Как открывается**: На фронтенде представлена в виде удобных вкладок интерфейса, на бэкенде — через эндпоинты, объединенные в роутер `adminRouter` под префиксом `/api`.

### 2.3 Платежи
* **Провайдеры**: 
  1. **ЮKassa**: Автоматический режим. При наличии рабочих ключей (`YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`) осуществляет прямой HTTP-запрос к `api.yookassa.ru/v3/payments` с автоматическим возвратом `confirmation_url` и сохранением транзакции.
  2. **СБП (Система Быстрых Платежей)**: Ручной режим. Если ключи ЮKassa отсутствуют, система автоматически переключается в ручной режим: предлагает пользователю перевести деньги по номеру телефона `SBP_PHONE` и отправить подтверждающую команду (например, «оплачено premium»).
* **Что работает**: Создание транзакции (`createPayment`), выбор тарифов подписки (`plan`, `premium`), сохранение платежных статусов в SQLite таблицу `payments`, обработка платежных команд внутри текстового/голосового чата через `handleFintechCommand` (`src/fintech/routes.ts`).

### 2.4 Голос (TTS/STT)
* **Синтез речи (TTS)**: Edge Neural TTS (класс `TTSService`). Высокое качество без задержек. Реализован двухэтапный каскад генерации:
  1. WebSocket-соединение через библиотеку `msedge-tts` с формированием аудиопотока.
  2. В случае сбоя — прямой HTTP SSML-запрос к отказоустойчивым серверам Microsoft Edge TTS.
  3. В случае полного отсутствия сети — генерация валидного локального офлайн WAV-тона в качестве резерва.
  Предусмотрено быстрое MD5-кэширование синтезированных фрагментов в ОЗУ, русскоязычная нормализация числительных и дат (`voiceNormalizer.ts`) и поддержка голосов `ru-RU-DmitryNeural` / `ru-RU-SvetlanaNeural`.
* **Распознавание речи (STT)**: Groq Whisper (`whisper-large-v3` через API `/audio/transcriptions`). На бэкенде реализовано подавление известных галлюцинаций Whisper (таких как «dimatorzok», «дима торжок», «продолжение следует», «спасибо за просмотр» и др.).

### 2.5 Vision
* **Что умеет**: Детально анализирует изображения, графики, код или логи на скриншотах.
* **Какие провайдеры**: Каскад из двух Vision-провайдеров:
  1. `qwen-groq` (модель `qwen/qwen3.6-27b` на API Groq Cloud).
  2. `free-gemma` (модель `google/gemma-3-27b-it:free` на API OpenRouter).

### 2.6 Библия
* **Функции**:
  * Годовой интерактивный план чтения Священного Писания «План Победы» (365 дней по расписанию).
  * Команда подписки/отписки в чате: «бог благ и милость его велика» (с защитой от случайного отключения ранее 30 дней использования).
  * Автоматический планировщик (`checkAndSendBibleBroadcast` запускается каждые 20 секунд) для отправки стихов строго по московскому времени:
    * **09:00** — Утренний стих (текстовый Синодальный перевод через `bible-api.com`).
    * **09:30** — Утренний богословский разбор стиха (голосовой ИИ-комментарий, синтезированный через Edge TTS).
    * **18:00** — Дневной стих (текст).
    * **18:30** — Дневной богословский разбор (голос).
    * **21:00** — Вечерний стих (текст).
    * **21:30** — Вечерний богословский разбор (голос).
  * Ручной тест рассылки командой «тест рассылки» (мгновенно отправляет в чат 3 тестовых стиха текстом и голосом).

### 2.7 Прочее
* **Персонализированные утренние брифинги (`morningBriefing.ts`)** — генерация сводки новостей и дел.
* **Прошивка ESP32 (папка `firmware/`)** — готовый исходный код микроконтроллера для подключения к Wi-Fi и интеграции физических IoT-кнопок с голосовым API Selin AI.
* **Pure SQLite WAL Mode** — все транзакции, сессии, подписки и логи пишутся в SQLite с включенным режимом WAL для многопоточной отказоустойчивости.

## 3. AI-ядро

### 3.1 Цепь провайдеров (в порядке вызова)
Для каждого запроса в `LLMService.ts` настроена автоматическая отказоустойчивая цепочка вызовов (Fallback Chain):
1. **Groq Cloud API** (высокоскоростной инференс моделей по приоритету: `llama-3.3-70b-8192`, `qwen`, `gemini`, `deepseek`).
2. **Google Gemini API** (модель `gemini-2.5-flash` по умолчанию через официальный SDK `@google/genai`).
3. **OpenRouter API** (каскад моделей: `google/gemini-2.5-flash`, `anthropic/claude-sonnet-4`, `meta-llama/llama-3.3-70b-instruct`, `qwen/qwen-2.5-72b-instruct`).
4. **Orca Router API** (резервный вызов модели `google/gemini-2.5-flash` через OpenAI-совместимый клиент).

### 3.2 Агенты
* **Orchestrator Ролей**: Динамически управляет системными инструкциями для 3 базовых ролей:
  * `general` — Помощник общего профиля (живой, конкретный стиль).
  * `expert` — Высококлассный аналитик (цифры, отчеты, структурирование).
  * `creative` — Креативный копирайтер (ритм, образы, копирайт).
* **Специализированные агенты в `src/agents/`**: Реестр ИИ-сотрудников (`CodingAgent`, `ContentAgent`, `NewsAgent`, `OrderAgent`, `TravelAgent`, `WeatherAgent`, `base.agent`, `business.agent`, `concierge.agent`, `sales.agent`, `support.agent`, `tutor.agent`).
* **Рой Специалистов (`SpecialistSwarm.ts`)**: Автоматически анализирует входящий запрос и в случае необходимости перенаправляет задачу на специализированный рой экспертов для максимального качества ответа.

### 3.3 Живые данные
В системный контекст ИИ-ядра жестко интегрированы:
* Точное московское время и календарная дата (обновляются при каждом запросе).
* Информация о погоде, поиске информации и статусе авиарейсов (`FlightService.ts`).

## 4. Безопасность

Архитектура безопасности Selin AI полностью соответствует стандартам безопасности **OWASP Top 10 for LLM 2026**:
* **AI Shield (`ai-shield.ts`)**: Очистка пользовательских промптов от скрытых атак, инъекций, удаление невидимых zero-width символов (`U+200B..U+FEFF`), нормализация NFKC.
* **RAG Protection (`rag-protection.ts`)**: Предотвращение Indirect Prompt Injection атак через загружаемые в базу знаний документы, изоляция текстовых блоков в тегах `<retrieved_document>`.
* **MCP Guardian (`mcp-guardian.ts`)**: Валидация JSON-схем инструментов MCP, вычисление SHA-256 хешей для предотвращения несанкционированных вызовов системных функций.
* **Output Filter (`output-filter.ts`)**: Сканирование генерируемого ИИ текста на предмет утечек учетных данных, приватных SSH/RSA-ключей, JWT-токенов и срабатывания Canary-токенов.
* **Jailbreak Detector (`jailbreak-detector.ts`)**: Алгоритмическое распознавание более 50 известных шаблонов взлома и обхода системных правил (DAN, Developer Mode и др.).
* **Trust Engine (`trust-engine.ts`)**: Начисление динамического рейтинга доверия пользователя (Multi-Turn Trust Score от 0 до 100) на основе истории его запросов и срабатываний защитных фильтров.
* **Canary Tokens (`canary-tokens.ts`)**: Расстановка скрытых токенов-приманок для моментальной блокировки при попытках извлечения данных (exfiltration).
* **Emergency Killswitch (`security.routes.ts`)**: Роут экстренного отключения ИИ-ядра в случае обнаружения критической атаки (`POST /api/security/killswitch`).

## 6. Текущий статус

### ✅ РАБОТАЕТ
* **Отказоустойчивое ИИ-Ядро**: Работа каскадной цепочки провайдеров (Groq -> Gemini -> OpenRouter -> Orca) с интеллектуальным роутингом ролей (General, Expert, Creative).
* **Распознавание речи (STT)**: Точная транскрибация Whisper-large-v3 со встроенной фильтрацией галлюцинаций.
* **Синтез речи (TTS)**: Edge Neural TTS высокого качества (с кэшированием в ОЗУ, каскадом WebSocket/REST и русским нормализатором числительных).
* **Голосовой мессенджер MAX**: Полноценный прием, отправка, Vision-анализ, inline-кнопки и обход лимитов за счет дробления сообщений.
* **База знаний и RAG**: Загрузка, удаление и парсинг документов (PDF, DOCX, TXT) с предотвращением Indirect Injection.
* **Безопасность ИИ (OWASP Top 10)**: Комплексная защита (AI Shield, RAG Protection, MCP Guardian, Output Filter, Jailbreak Detector, Trust Engine, Canary Tokens, Killswitch).
* **Годовой библейский План Победы**: Рассылка по московскому расписанию текстовых стихов и ИИ голосовых разборов для активных подписчиков.
* **Админ-дашборд**: Управление настройками, мониторинг метрик, выгрузка системной ленты событий, модерация ответов и аудит безопасности.
* **Автономная прошивка ESP32**: Код прошивки микроконтроллера для голосового общения с Selin AI по кнопке.

### ⚠️ ЧАСТИЧНО
* **Автоматические платежи ЮKassa**: Функция готова и протестирована, при отсутствии рабочих ключей мерчанта платформа автоматически переключается на СБП-команды в ручном режиме.
* **Цифровой Рубль**: Архитектурный фундамент и интерфейсы подготовлены, ожидают боевых ключей Robokassa или ЦБ РФ для полной реализации провайдера.
* **Внешние коннекторы (Instagram, Taxi, Food, Travel)**: Интегрированы в ИИ-агентов, но боевые вызовы требуют рабочих API-ключей сторонних сервисов.
* **Адаптеры Telegram, Robot, Web**: Описаны интерфейсы и логика, полностью готовы к привязке боевых токенов API.

### 📅 ЗАПЛАНИРОВАНО
* Прямая глубокая интеграция с платежным шлюзом API Центрального Банка РФ для Цифрового Рубля.

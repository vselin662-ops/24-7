# 🔊 Прошивка Умной Голосовой Колонки Selin AI 2.0 (ESP32-S3)

Полнофункциональная прошивка для автономного аппаратного клиента (умной колонки) платформы **Selin AI 2.0** на базе микроконтроллера **ESP32-S3**.

---

## 🛠️ Аппаратные компоненты

| Компонент | Модель | Назначение |
|---|---|---|
| **Микроконтроллер** | ESP32-S3 DevKitC-1 (N16R8 / 16MB Flash, 8MB PSRAM) | Главный процессор (Dual-Core 240MHz, Wi-Fi) |
| **Микрофон** | I2S INMP441 | Высокочувствительный цифровой всенаправленный микрофон |
| **ЦАП / Усилитель** | I2S MAX98357A (Class D 3W) | Цифровой усилитель звука для динамика 4-8 Ом |
| **Динамик** | 3W – 5W, 4Ω / 8Ω | Воспроизведение синтезированной речи Selin AI |
| **Индикация** | WS2812B RGB LED кольцо (12 LED) | Визуальная обратная связь состояний диалога |
| **Датчик движения** | PIR HC-SR501 / AM312 | Детекция присутствия человека в комнате |

---

## 📌 Схема подключения пинов (Pinout)

### 1. Микрофон INMP441 (I2S RX) -> ESP32-S3
| INMP441 Pin | ESP32-S3 GPIO | Описание |
|---|---|---|
| **VDD** | 3.3V | Питание |
| **GND** | GND | Земля |
| **SD** | **GPIO 6** | Serial Data (Выход данных) |
| **WS (L/R CLK)** | **GPIO 5** | Word Select (Выбор канала) |
| **SCK (BCLK)** | **GPIO 4** | Bit Clock (Тактовый сигнал) |
| **L/R** | GND | Выбор левого канала (Left channel) |

---

### 2. Усилитель MAX98357A (I2S TX) -> ESP32-S3
| MAX98357A Pin | ESP32-S3 GPIO | Описание |
|---|---|---|
| **Vin** | 5V (или 3.3V) | Питание усилителя |
| **GND** | GND | Земля |
| **DIN** | **GPIO 7** | Data In (Вход аудиосигнала) |
| **BCLK** | **GPIO 15** | Bit Clock |
| **LRC (WS)** | **GPIO 16** | Left-Right Clock |
| **SD_MODE** | Не подключен / 3.3V | Включение (активен по умолчанию) |
| **GAIN** | GND | Коэффициент усиления (12dB) |

---

### 3. Светодиоды WS2812B & Датчик PIR
| Устройство | Пин устройства | ESP32-S3 GPIO |
|---|---|---|
| **WS2812B LED** | DIN (Data In) | **GPIO 48** (или GPIO 8) |
| **WS2812B LED** | 5V / GND | 5V / GND |
| **PIR Датчик** | OUT (Data Out) | **GPIO 14** |
| **PIR Датчик** | VCC / GND | 3.3V / GND |

## 🌈 Светодиодная индикация состояний

- 🔵 **Вращающийся синий огонек**: Подключение к Wi-Fi / WebSocket серверу.
- 🟢 **Пульсирующий зеленый**: Детекция голоса и запись речи пользователя (VAD).
- 🟡 **Вращающийся золотой луч**: ИИ думает (обработка запроса мультиагентным оркестратором).
- 🟣 **Радужная волна**: Колонка воспроизводит ответ ассистента.
- 🟠 **Оранжевая вспышка**: Срабатывание датчика движения (приветствие).
- 🔴 **Мигающий красный**: Ошибка связи с сервером.
- 🌊 **Бирюзовое дыхание**: Режим ожидания (Idle).

## 🚀 Сборка и прошивка

### Вариант 1: Через PlatformIO (VS Code / CLI)

1. Откройте директорию `firmware/` в VS Code с установленным расширением PlatformIO.
2. В файле `firmware/include/config.h` укажите ваши учетные данные:
   ```c
   #define WIFI_SSID         "Ваш_WiFi"
   #define WIFI_PASSWORD     "Ваш_Пароль"
   #define WS_SERVER_HOST    "192.168.1.100"  // IP вашего сервера Selin AI
   #define WS_SERVER_PORT    3000
   ```
3. Скомпилируйте и прошейте плату:
   ```bash
   pio run -t upload
   pio device monitor
   ```

### Вариант 2: Через Arduino IDE

1. Установите поддержку плат `esp32` от Espressif (версия 2.0.14+ или 3.0+).
2. Выберите плату: **ESP32S3 Dev Module**.
3. Включите настройки:
   - **PSRAM**: OPI PSRAM (или QSPI в зависимости от модуля)
   - **Flash Size**: 16MB
   - **USB CDC On Boot**: Enabled
4. Установите библиотеки через Library Manager:
   - `WebSockets` (by Markus Sattler)
   - `ArduinoJson` (v7+)
   - `FastLED`
5. Откройте `firmware/src/main.cpp` (или скопируйте в `main.ino`), укажите настройки в `config.h` и нажмите **Upload**.

## 📡 Протокол взаимодействия с сервером Selin AI

Умная колонка подключается по WebSocket к `ws://<SERVER_IP>:3000/ws/colonna`:
- При обнаружении голоса передает бинарные PCM фреймы (16kHz, 16bit, Mono).
- По окончании речи отправляет JSON `{ "type": "audio_end", "speakerId": "selin_speaker_s3_1" }`.
- Принимает ответ `{ "type": "response", "text": "...", "audioBase64": "..." }`, декодирует и мгновенно воспроизводит через ЦАП MAX98357A.
